# 来源核验记录 · 2026-10-25

本轮按公开原始来源检查 17 个论文条目；记录区分可读正文、官方检索索引与尚未完成的复核。预印本年份按首次公开年份，正式出版标签按来源依据。这里不是“全部外链或全部全文通过”的声明。

本轮将 VLIF 从 Preprint 2025 更新为已有正式记录的 AAAI 2026，并补 NeurIPS 正式来源。SPIDEN 正文把 arXiv:2305.11898 列为独立参考文献，故不再把该链接当作同一论文预印本。新增 SpikeRestormer（统一 SNN 图像复原）与 EM-SNN（SNN 遥感去雾），均来自已核验的公开 arXiv，按预印本标注。

现有 15 篇加 2 篇公开预印本，共 17 篇。未新增许可，也未把外部论文、图片、代码或数据改授 MIT。

## 数据集与工具入口

README 为原有数据集组补上原始发布页、原始论文或注明身份的作者评测副本：BSD68/Set12（DnCNN 副本）、CIFAR-10、Rain12/200 原始论文、Rain1200（DID-MDN）、RESIDE/SOTS、Dense-Haze、UIEB、EUVP、Set5/Urban100（SwinIR 副本）、LOL、SDSD、AID、DOTA。DIOR 通过已核验的 SpikeSR 作者实验说明进入，未使用无法复核的旧 escience URL。StereoWaterdrop 目前提供 SNNSIR 的协议与原始参考文献入口，不声称已找到独立下载地址。

- 原始页已核对：CIFAR、Berkeley、RESIDE、Dense-Haze、UIEB、EUVP、AID、DOTA。
- GitHub 作者 README/目录已核对：DnCNN 的 BSD68/Set12，RetinexNet 的 LOL，DID-MDN 的 Rain1200，SDSD 的视频数据，SwinIR 的评测副本说明；不把这些维护副本冒充原始数据所有者。
- SNN 框架与列出的代码仓库均通过 GitHub API 核验存在；Lava 仓库已归档，已标注。未安装或运行这些模型。
