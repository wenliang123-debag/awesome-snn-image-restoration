- [Layer-Wise Spike Modulation for Structure-Aware Image Denoising with Spiking Neural Networks](https://www.mdpi.com/2076-3417/16/20/10391): Combines ResNet features with layer-wise LIF modulation for image denoising.

## Image Dehazing

- [ReBo-SNN: Boosted spiking neural network with retina mechanism for efficient haze removal](https://doi.org/10.1016/j.neunet.2026.109428): Uses a retina-inspired spiking network for single-image dehazing. Published online in 2026; assigned to the January 2027 issue.

- [EM-SNN: Efficiently Modulated Spiking Neural Network for Remote Sensing Image Dehazing](https://arxiv.org/abs/2610.09275): Threshold and structural modulation for SNN remote-sensing dehazing.

- [Learning a density-guided adaptive spiking network for remote sensing image dehazing (DASNet)](https://www.nature.com/articles/s41598-026-80033-y): Adapts spiking neuron dynamics to the estimated haze density.

## Low-Light Image Enhancement

- [A Dual-Domain Synergistic Network with Frequency-Guided Neuromorphic Adaptation for low-light fundus image enhancement (DDSN)](https://doi.org/10.1016/j.knosys.2026.116809): Uses frequency-guided spiking thresholds and spatial refinement in a hybrid SNN–ANN model for fundus images.
